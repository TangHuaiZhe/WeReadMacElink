# WeReadMacElink

一个面向外接墨水屏的本地 macOS 微信读书阅读外壳，重点解决官方 iPad 版本在 Mac 外接墨水屏上字号偏小、对比度不足、动画过多和正文栏过窄的问题。

应用使用微信读书官方网页完成登录、内容展示和进度同步，并可选地通过官方智能体接口查询书籍与阅读统计；显示效果只在本地调整。它不会提取登录凭证、拦截接口、解密、下载或保存书籍正文。

## 为什么不直接使用网页版

这个项目并不是独立的微信读书客户端，而是面向 **Mac 外接墨水屏长期阅读** 的专用适配层。它保留网页版的正版内容、账号体系和进度同步，同时提供浏览器与官方客户端没有集中提供的墨水屏显示控制。

| 方面 | 微信读书网页版 | WeReadMacElink |
| --- | --- | --- |
| 字号 | 依赖网页设置或浏览器缩放 | 支持 100%–200% 页面缩放，并触发正文重新排版 |
| 正文宽度 | 主要由网页布局决定 | 上下滚动模式可在窗口宽度的 60%–95% 之间调节 |
| 对比度 | 跟随网页主题 | 可同时增强整体对比度、文字墨色和笔画粗细 |
| 色彩 | 保留网页原色 | 可一键灰阶化，减少墨水屏灰色层次干扰 |
| 动画 | 包含网页动画和滚动效果 | 可关闭动画，减少残影和刷新闪烁 |
| 文字选择 | 默认半透明高亮 | 使用墨水屏上更清楚的黑底白字高亮 |
| 网页工具栏 | 正文加宽后可能覆盖内容 | 上下滚动模式会将工具栏移到正文外侧 |
| 设置保存 | 浏览器缩放与网页设置相互独立 | 字号、宽度、对比度、灰阶和动画设置统一保存在本机 |
| 阅读环境 | 与其他网页标签混合 | 独立窗口和固定控制栏，减少浏览器界面干扰 |

它的核心价值是更稳定的墨水屏显示和更少的重复调整。如果只使用普通液晶显示器，并且浏览器缩放已经满足需求，直接使用微信读书网页版通常就足够了。

## 功能

### 墨水屏显示

- 字号使用 WebKit（苹果网页引擎）页面缩放，支持 100%–200%，能够触发网页重新排版。
- 对比度同时增强整体反差、文字墨色和笔画粗细，支持 100%–200%。
- 上下滚动阅读模式可将正文宽度调整为窗口的 60%–95%。
- 上下滚动模式的网页工具栏会自动移到正文右侧，不遮挡文字。
- 选中文字使用适合墨水屏的黑底白字高亮。
- 可关闭网页动画和滚动动画，减少墨水屏残影。
- 可一键灰阶化，减少墨水屏灰色层次干扰。
- 字号、对比度、正文宽度、灰阶和动画设置自动保存在本机，可随时恢复墨水屏默认值。

### 阅读与导航

- 顶部控制栏提供首页、后退、前进和刷新，并集中放置字号、对比度、正文宽度的加减按钮。
- 控制栏显示微信读书官方的全书阅读进度（百分比与进度条），仅在进入阅读页后出现。
- 自动识别阅读页当前布局：处于双栏横向翻页模式时，控制栏会提示「双栏模式：宽度与墨色不生效」，并停用正文宽度按钮。
- 自动识别窗口所在显示器并显示其名称。
- 支持 `⌘K` 打开原生电子书搜索，并使用微信读书返回的官方链接跳转；已下架书籍会标注并禁用。
- 非微信读书域名的链接交由系统默认浏览器打开。

### 阅读统计

- 独立统计栏显示微信读书官方的阅读时长：今天、本周、本年。
- 进入某本书后追加显示「本书」已读时长，并按官方进度估算「预计剩余」时长。
- 应用重新激活或切换书籍时自动刷新，也可用统计栏右侧按钮手动刷新。
- 统计只读取官方返回的时长与进度数字，不读取正文内容。

## 系统要求

- macOS 13 或更高版本。
- Xcode 及 Swift 6 工具链。
- 网络连接和可正常使用的微信读书账号。
- 微信读书 Agent API（智能体接口）密钥，仅搜索与阅读统计需要。

## 构建与运行

电子书搜索和阅读统计需要先设置微信读书 Agent API（智能体接口）密钥：

```bash
export WEREAD_API_KEY=<你的apikey>
```

应用只从环境变量读取密钥，不会把密钥写入仓库、网页脚本或偏好设置。未设置密钥时，正文阅读和显示调节不受影响，只有搜索与阅读统计会提示密钥缺失。

```bash
swift test
./scripts/build-app.sh
open dist/WeReadMacElink.app
```

`open` 会继承当前 shell 的环境变量，所以上面的 `export` 对随后启动的应用有效；也可以直接运行 `dist/WeReadMacElink.app/Contents/MacOS/WeReadMacElink` 从终端启动并查看输出。

构建脚本会生成并进行本地临时签名（ad-hoc 签名，未做公证，因此 Gatekeeper 的 `spctl` 会拒绝，这是本地自用的预期结果）：

```text
dist/WeReadMacElink.app
```

## 快捷键

- `←` / `→`：上一页 / 下一页。
- `⌘+` / `⌘-`：增大 / 减小字号。
- `⌘K`：打开原生电子书搜索。
- 菜单「阅读 › 恢复墨水屏默认设置」：把字号、对比度、正文宽度、灰阶和动画恢复为本项目默认值。

## 隐私和使用边界

- 登录会话由 WebKit 默认数据存储管理，项目代码不会读取或上传 Cookie（网站登录凭证）。
- 项目不调用微信读书私有正文接口，也不导出受版权保护的内容。
- 电子书搜索和阅读统计通过微信读书官方智能体接口（`https://i.weread.qq.com/api/agent/gateway`）完成，只发送搜索关键字或书籍 ID，只取回书名、作者、阅读时长和进度；智能体密钥仅用于该请求头，不写入磁盘。
- 阅读统计不做本机计时，也不会把阅读行为上报到微信读书以外的任何服务。
- 项目仅调整用户本机上的页面显示效果。
- 请遵守微信读书用户协议及适用法律。

## 当前限制

- 本项目仍以微信读书网页版为阅读引擎，不提供离线下载、独立正文管理或原生批注同步。
- 页面样式依赖微信读书网页版当前的容器类名；官网改版后可能需要同步更新 `EInkStyle.swift`。
- 阅读进度与书籍 ID 依赖阅读页当前的前端结构，官网改版后可能读不到，此时进度显示会隐藏，正文阅读不受影响。
- 阅读时长与单书进度依赖官方智能体接口；未配置密钥或接口不可用时，统计栏和搜索会提示不可用。
- 双栏横向翻页模式的正文由站点预渲染到画布，字号（页面缩放）、灰阶和整体对比度仍然有效，但正文宽度与文字墨色、笔画调整无法作用于正文；控制栏会在该模式提示，上下滚动模式不受此限制。
- 当前仅针对 macOS 和外接墨水屏进行设计与验证。
- 本项目与腾讯或微信读书没有隶属、授权或合作关系。
